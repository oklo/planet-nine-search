        Reading the map

        Purple shows where Planet Nine would have appeared in 2018 along the 21,740 Brown–Batygin orbits still allowed by earlier searches. The scale gives the percentage of those orbits per square degree, smoothed over 2°.

        Green dots mark fields. Zoom in to see the patch of sky imaged in each TESS sector. Stronger green means the search more reliably picked up artificial planets added to the images. The faintest green marks fields with no demonstrated recovery.

        Field labels show how many test planets were found and the brightnesses tried (T for TESS magnitude, V for visual magnitude). “Recovery tests pending” means the field has no published test result yet. Select a field for the counts at each brightness.

        An open green square marks a field with a path on display for visual review. Several paths can pick up the same light. Open “Fields for visual review” to compare visits, read what makes each path interesting or doubtful, and vote.
